# Plantilla de Caso de Uso

## 1) Usuario principal
¿Quién usará el sistema?

## 2) Contexto del usuario
¿En qué situación lo usaría y con qué objetivo?

## 3) Situación inicial
¿Qué tiene el usuario antes de ejecutar el programa?

## 4) Flujo principal (paso a paso)
Describe el flujo ideal numerado:
1.
2.
3.
4.

## 5) Flujo alternativo
¿Qué variación común puede ocurrir?

## 6) Errores posibles
Lista errores esperados y cómo se comunicarán al usuario.

## 7) Resultado esperado
¿Qué obtiene el usuario al final?

## 8) Ejemplo de uso en terminal
Incluye un ejemplo breve:

```bash
# ejemplo (ajústalo a tu proyecto)
./scripts/run.sh
```

## 9) Viabilidad del caso de uso
Explica por qué este caso de uso es pequeño, acotado y viable para esta actividad.
