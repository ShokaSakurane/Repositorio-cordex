# Checklist Breve de Validación

## 1) Checklist de pruebas mínimas
- [ ] Ejecuté el flujo principal al menos una vez.
- [ ] Probé al menos una entrada inválida.
- [ ] Confirmé que el resultado coincide con lo esperado.
- [ ] Registré evidencia en `docs/plan_de_pruebas.md`.

## 2) Checklist de documentación
- [ ] Completé `docs/propuesta.md`.
- [ ] Completé `docs/caso_de_uso.md`.
- [ ] Revisé `docs/estructura_repositorio.md`.
- [ ] Completé `docs/plan_de_pruebas.md`.

## 3) Checklist de ejecución
- [ ] `scripts/run.sh` tiene permisos de ejecución.
- [ ] `scripts/run.sh` corre sin depender de red.
- [ ] El proyecto funciona con alcance pequeño.

## 4) Checklist de entrega final
- [ ] El repositorio está ordenado y sin archivos basura.
- [ ] El objetivo del proyecto está claramente definido.
- [ ] El alcance está limitado y es viable.
- [ ] La entrega está lista para revisión en GitHub Classroom.
